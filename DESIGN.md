# Правила дизайна Math Check

Эти правила обязательны для каждого экрана и письма.

1. **Вложенные радиусы.** Радиус внутреннего элемента = радиус внешнего блока − отступ между ними. Все размеры с шагом 4 px.
   Кнопки, поля и переключатели — «таблетки» (радиус = половина высоты), карточки 28, отступ внутри карточек 24.
2. **Две вертикальные линии текста.** Край карточек: логотип, заголовок страницы. Линия текста внутри карточек (+24 px): названия блоков, подписи и сообщения под карточками.
3. **Общая базовая линия.** Текст в одной строке выравнивается по нижней (базовой) линии, а не по центру: подписи разного размера стоят на одной линии.
4. **Подписи над полями** начинаются там же, где текст внутри поля (+16 px от края поля).
5. **Логотип внутри приложения** — монохромный, спокойный. Цветной — в письмах, иконках, соцсетях.
6. **Движение** — по токенам из «Токены движения» (index.html): только transform и opacity; вход с перелётом, уход без; «меньше движения» — 1 мс.
7. **Не добавлять от себя** элементы и данные, которые не согласованы: идеи — текстом, решение за владельцем.
