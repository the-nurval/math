# Math Check — контекст для Claude Code

Сайт-генератор контрольных по математике для 5–9 классов (готовы 6, 7 и 8), три языка (ru/et/en), роли «ученик» и «родитель».
Владелец проекта общается по-русски. Отвечай по-русски, коротко и по делу.

## Как работать с владельцем
- Он решает, ты делаешь. Не принимай решений сам и не «додумывай»: идеи предлагай текстом и спрашивай.
- В макетах не добавляй элементы и данные, о которых не просили.
- Изменения дизайна сначала показывай картинкой или макетом, потом переносишь на сайт после его «ок».
- Правила дизайна — в `DESIGN.md`, они обязательны. Особенно: вложенные радиусы с шагом 4 px, подписи над полями на +16 px, связанные элементы рядом, а не по краям.
- Программы классов: всегда сравнивай программы СССР (по возрасту), РФ и Эстонии и бери максимум по глубине. Если в Эстонии тема слабее — дай больше. Сайт не должен писать, что он «по эстонской программе». Перед написанием заданий класса присылай таблицу сравнения и программу по неделям на согласование.
- Олимпиадные задачи и доказательства — фиксированные, не генерируются. Ответы не должны быть все «красивыми». Работы по размеру как настоящие контрольные.

## Устройство
- Статический сайт без сборки, ES-модули грузятся браузером напрямую. Карта папок — в `README.md`: `src/` (интерфейс), `generator/` (генератор, без DOM), `css/`, `tests/`, `config.js` (Supabase URL и публичный ключ).
- Правила кода: один файл — одна задача, до ~300 строк (длиннее только данные: тексты, олимпиадные задачи, конспекты); изменяемое состояние только в `src/state.js`; кнопки — через `src/actions/` (data-act / data-go / data-set); повторяющийся код выносить в общую функцию, если это не усложняет; стиль — Prettier (`npm run format`), строка до 100 символов.
- Новый класс: `generator/grades/N/` по образцу 8-го (topics, tasks/<тема>.js, olympiad, proofs, summaries/<язык>.js, index.js) и строка регистрации в `generator/index.js`.
- Хостинг: Vercel, https://math-nurval.vercel.app, деплой при push в `main` репозитория the-nurval/math. Служебные файлы не выкладываются (`.vercelignore`).
- Supabase: `supabase/schema.sql` (таблицы, RLS, функции; файл можно запускать повторно), функция писем `supabase/functions/send-mail/index.ts` (в Supabase её адрес `bright-processor`, имя send-mail; nodemailer через SMTP info@nurval.ee). Владелец сам вставляет SQL и код функции в панель Supabase — давай ему готовые файлы и пошаговые инструкции, куда нажимать.
- Секреты (SMTP-пароль, service_role) в репозиторий не попадают и в чат не просятся.
- Темы новых классов — с префиксом (`g6div` и т. п.), у темы есть цвет `col`. Работа хранит свой класс в `meta.grade`; смешанная работа — `meta.grades`.
- Типы ответов: `num`, `set`, `choice`, `std`, `self`, `frac` (несократимая дробь). Периодические дроби вводятся как `0,(45)`.

## Проверка перед отправкой
- `npm test` — генератор: все правильные ответы засчитываются, нет `undefined/NaN`, нет кириллицы в et/en, выдача совпадает со снимком `tests/generator-snapshot.json`. Снимок обновлять (`npm run snapshot`) только при намеренном изменении заданий; изменения в общей части не должны менять выдачу других классов.
- `npm run test:ui` — Playwright с подменой ответов Supabase: экраны ученика и родителя на трёх языках без ошибок в консоли, скриншоты в `tests/screens/`.
- Коммиты на русском, коротко, что изменилось для пользователя.

## Что сейчас в работе
- Шапка экрана работы (сделано и на сайте). Развёрнутый вид — вариант A на холсте: список настроек, слева колонка названий 136 px, справа элементы; строки Дата, Таймер, Класс (цифры 5…9 и «Смешивать классы» в 40 px от них), Тип работы; тонкие линии между строками от линии текста (+24 px) до правого края кнопки «Скрыть настройки» (−24 px); внизу «Новая работа» и «Скрыть настройки». Свёрнутый вид — вариант B: одна строка кнопок-фильтров с теми же значениями в том же порядке, клик открывает окошко выбора, справа кнопка разворота и «Новая работа». Выбор вида запоминается. Блок «Учебная неделя N из 35» остаётся под шапкой в обоих видах (без периода и каникул). Кнопка «Развернуть» у работы прячет и шапку, и неделю. «Смешивать классы» — кнопка без переключателя: светлая, нажатая темнее; классы при смешивании остаются, но неактивны.
- Программа: по умолчанию «Школьная» — темы в школьном порядке и по датам, но с максимальной глубиной из трёх программ (Easy/Medium/Hard остаются отдельно). В Настройках опция «Прогрессивная программа»: темы в темпе РФ/СССР, раньше (например, квадратные уравнения в 8 классе). Уровень сложности и программа — две разные настройки.
- 8 класс готов (программа в `docs/program-8.md`, переключатель «Школьная / Прогрессивная» в настройках). Следующие — 5 и 9 (сравнение программ → согласование → генератор → конспекты → проверка).
- Отложенные идеи (не делать без запроса): бонусы за прогресс, настройки уведомлений по действиям и частоте, смена почты аккаунта, экзамен 9 класса, Enter в полях ответа → следующее поле.
- Макеты лежат на холсте «Math Check — дизайн сайта» в Claude (артефакт), там же базовые принципы.
